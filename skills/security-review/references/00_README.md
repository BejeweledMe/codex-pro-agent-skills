# Security review references

Choose depth according to the claim and consequences; these references do not require a universal report template or review committee.

| Reference | Use when |
|---|---|
| [Review scope and assurance](review-scope-and-assurance.md) | Framing scope, challenging authority and composition, examining independence or recovery assumptions |
| [Evidence register and findings](evidence-register-and-findings.md) | Selecting evidence, resolving contradictions, recording findings, exceptions and retest status |
| [Application and release review](application-release-review.md) | Assessing application controls, ASVS applicability, release integrity and deployed correspondence |
| [Repository and OSS review](repository-ossf-review.md) | Assessing dependencies, repository/CI policy, OSPS, Scorecard, scanner suppressions and supplier evidence |
| [Source versions and refresh](source-versions-and-refresh.md) | Making exact or current standards, protocol, tooling or provider claims |

Supply-chain terms are defined locally where used; no neighboring skill's physical files are required.
