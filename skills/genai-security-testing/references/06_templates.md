# Templates

## Threat Model

Record: system and owner; assets; callers/tenants; trusted and untrusted inputs; data classes; tools and effects; identities; trust boundaries; high-consequence intersections; controls; assumptions; recovery owner.

## Authorized Test Plan

Record: authorization; environment/accounts; approved slices; data handling; caps; stop path; reset procedure; protocol; evidence collection; reporting owner; rollback/recovery owner.

## Finding And Regression Case

Record: redacted symptom; affected boundary; expected behavior; actual outcome; system bundle; evidence/trace IDs; impact; containment; fix; regression grader; release gate; owner. Do not include secrets, protected data, or reusable third-party bypass instructions.
