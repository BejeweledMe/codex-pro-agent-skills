# Structure and navigation

Use this for substantial prose whose grouping or entry points affect what readers can find and understand. Apply it under the current source and artifact contract; a table in a report does not turn it into a presentation.

## Select a route through the material

If selection is stuck, connect three things internally: why the reader would use the text, what understanding or action it can support, and which available facts or examples earn that result. This is a planning aid, not a mandatory visible brief. Curiosity, orientation, and complete reference coverage are valid purposes without a call to action.

Decide which parts must be read in order and which answers readers should retrieve independently. A cumulative explanation needs connecting context; a reference, comparison, or long report needs informative headings and openings. A mixed document can have a short main path plus labeled detail. A difficult thesis may need preparation before its conclusion.

Choose an order that fits the material: event first for a notice, meaningful actions for an account, shared fields for a comparison, or prerequisite concepts before an explanation. A conclusion-first report can preserve chronology in its evidence. Do not force a story around material that supplies no actions or causal sequence.

## Read entry points without their parents

Read headings, option labels, paragraph openings, and likely search destinations as a reader arriving midway would. Is the subject clear? Does the action retain its condition, scope, and polarity? Repetition that preserves these is useful.

Hypothetical supplied rule: external reference notes are prohibited during an assessment. Under the parent heading “Actions prohibited during an assessment,” a child heading “Use external reference notes” loses the prohibition in a contents view. “Do not use external reference notes during the assessment” preserves it. No new condition has been introduced.

When neighboring sections are “Monthly plan → Limits” and “Annual plan → Limits,” readers may lose the option identity. Use local titles such as “Annual-plan limits,” compare both plans under each criterion, or retain the hierarchy with clearer navigation. Necessary hierarchy in a large reference is not a defect.

## Make openings form a usable map

Read only the paragraph openings. They should supply enough topic and progression cues for the intended path. Repair missing antecedents, avoidable time jumps, and accidental topic drift. A deliberate contrast can depend on the previous paragraph; an evidence chain can need a long paragraph. Neither calls for mechanical splitting.

If scattered bold fragments create disconnected keywords, move the meaningful proposition into a heading or opening. Keep emphasis when it identifies a useful value, warning, or contrast. Formatting cannot supply a missing relationship.

For an accepted long draft whose restructuring is authorized, group related material and put each section's current answer before its background where appropriate. An opening summary can collect those answers. Summary/body repetition can support two reading depths. A current request, or an explicit “no action needed,” is useful when the reader would otherwise be unsure; neither is mandatory in every document.

## Choose list, table, or section by the reader's task

Before using bullets, identify what is being enumerated. Keep comparable semantic levels and repeated fields in a consistent order; ensure the lead-in applies grammatically and logically to each item. A narrative or developed argument may need paragraphs or sections.

Put a recognizable situation before an unfamiliar option name when it helps readers choose. Hypothetical supplied options are Orchid for view-only access and Cedar for editing access. “Need to edit files? Cedar provides editing access” can help a novice; a familiar administrator may prefer the tier name first.

A table is useful when several repeated attributes need comparison. Move a common condition outside individual entries only when it truly applies to all and remains easy to find. Do not turn cumulative conditions into a menu of alternatives.

## Give openings and endings a job

An opening can answer directly or clarify coverage, prerequisites, difficulty, or a route through a long artifact. Include only orientation the reader needs. Change a promise the body cannot support, or identify the missing material. A scene or quotation can be appropriate when it carries the requested meaning.

An ending can supply a shared caveat, warranted conclusion, return path, or requested next action. A long request may repeat the same ask at the beginning and end because those positions serve different reading moments; keep amounts, dates, and commitments consistent. Omit a closing paraphrase that adds no value to a short text.
